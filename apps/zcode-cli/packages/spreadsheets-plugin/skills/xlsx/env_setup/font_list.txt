# Font list

Fonts the xlsx skill's workbooks name, and the ones LibreOffice substitutes
when they are missing. Workbook font choice is mostly the *consumer's* problem
— a workbook opened on a machine without the named face falls back, and the
fallback's metrics re-wrap every cell. This list exists so that risk is a
decision, not an accident.

The list is factual data — font family names and their sources — not a
redistribution of the fonts themselves.

## The safe default

**Calibri** (Excel's own default) and **Carlito** (its metric-compatible
substitute, shipped with LibreOffice) are the safest pair: a workbook written
with Calibri on a machine with LibreOffice renders with Carlito at the same
metrics, so nothing re-wraps.

| role | primary | metric-compatible fallback |
| --- | --- | --- |
| body / UI | Calibri | Carlito |
| headings | Calibri / Cambria | Carlito / Caladea |
| monospace | Consolas | Inconsolata |
| CJK | Microsoft YaHei / SimSun | Noto Sans CJK / Noto Serif CJK |

## Families worth having installed

| family | source |
| --- | --- |
| Carlito, Caladea | `fonts-crosextra-carlito` / `fonts-crosextra-caladea` (Debian), or the LibreOffice bundle |
| Noto Sans / Serif CJK | `fonts-noto-cjk` (Debian), `brew install font-noto-sans-cjk-sc` |
| DejaVu Sans / Sans Mono | ships with most Linux distributions |
| Liberation Sans / Mono | `fonts-liberation` — metric-compatible with Arial / Courier New |
| Inconsolata | `fonts-inconsolata` |

## Diagnosing a substitution

The render is the ground truth: export the sheet to PDF
(`scenes/convert.md`) and read it. A workbook whose columns silently widened,
whose numbers show as `####`, or whose dates changed format is showing a font
substitution — the substituted face's metrics differ, and the column widths
set for the original face no longer fit.

There is no `pdffonts`-style check for a workbook (the font is a name in the
file, resolved by the consumer); the PDF export is the check.

## Rules

- Name fonts that exist on the machines that will open the workbook, or accept
  the metric-compatible fallback above.
- Never set a font per cell when a column-level or workbook-level default will
  do — a per-cell font is what makes a font migration a find-and-replace
  project.
- CJK workbooks: the named face must exist on the rendering machine, or the
  PDF export shows tofu. Noto CJK is the portable choice.
