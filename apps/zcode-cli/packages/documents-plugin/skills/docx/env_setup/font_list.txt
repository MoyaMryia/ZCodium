# Font list

Fonts the docx skill's documents name, and the substitution risk that comes
with them. A `.docx` stores font *names*, resolved on the machine that opens
it: a face missing there is substituted, the substituted metrics re-wrap every
paragraph, and the document the author approved is not the document the reader
sees. This list exists so that risk is a decision.

The list is factual data — font family names and their sources — not a
redistribution of the fonts themselves.

## The safe pairs

| role | primary | metric-compatible fallback |
| --- | --- | --- |
| body (serif) | Times New Roman | Liberation Serif |
| body (sans) | Arial | Liberation Sans |
| headings | Calibri | Carlito |
| monospace | Courier New | Liberation Mono |
| CJK (Chinese) | SimSun / Microsoft YaHei | Noto Serif CJK SC / Noto Sans CJK SC |

The Liberation family is metric-compatible with the Times/Arial/Courier trio,
which is why a document that names Times New Roman renders with Liberation
Serif at the same line breaks on a Linux machine without Microsoft fonts.

## Families worth having installed

| family | source |
| --- | --- |
| Liberation Sans / Serif / Mono | `fonts-liberation` (Debian/Ubuntu) |
| Carlito, Caladea | `fonts-crosextra-carlito` / `fonts-crosextra-caladea` |
| Noto Serif / Sans CJK | `fonts-noto-cjk` (Debian), `brew install font-noto-serif-cjk-sc` |
| DejaVu Sans / Serif | ships with most Linux distributions |

## Diagnosing a substitution

- Export the document to PDF (LibreOffice headless, `soffice --headless
  --convert-to pdf`) and read the result: re-wrapped paragraphs, changed line
  counts, a table that grew a row — all symptoms of a substituted face.
- `pdffonts document.pdf` on the export lists the faces actually used; a face
  the document did not name is a substitution.
- A font that exists only on the build machine is a defect, not a portability
  detail — either install it where the document will be read, or change the
  document to name a face that exists there.

## Rules

- Name fonts that exist on the machines that will open the document, or accept
  the metric-compatible fallback explicitly.
- Set the font through the document's style definitions (the docx `styles.xml`
  defaults), not per run — a per-run font is what makes a font migration a
  find-and-replace project.
- CJK documents: the named face must exist on the rendering machine or the PDF
  export shows tofu. Noto CJK is the portable choice.
